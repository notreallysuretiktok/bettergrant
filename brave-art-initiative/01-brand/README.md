# Brand

## Logo files to produce (once a concept is picked)

Every logo should exist in each of these versions:

| Version | Formats | Used for |
|---|---|---|
| Primary (mark + wordmark, horizontal) | SVG, PNG (transparent), PDF | Website header, letterhead, grant docs |
| Stacked (mark above wordmark) | SVG, PNG | Social profile, merch, square spaces |
| Icon only | SVG, PNG 512×512, ICO | Favicon, app icon, watermark |
| Wordmark only | SVG, PNG | Narrow banners, email footer |

Each in: full color, all-white (for dark backgrounds), all-black (for print/fax/forms).

## Direction pulled from existing covers

The podcast one-sheet and the "Life After the Cult" covers already share a look worth keeping:

- **Colors:** near-black, warm antique gold, cream/off-white, with a muted army olive as an accent
- **Type:** bold condensed sans for headlines (one-sheet style), classic serif for elegance (magazine masthead style), one brush-script accent used sparingly ("My Daughter. My Why.")
- **Texture:** gritty, cinematic, warm light, real faces

Lock exact hex codes and font names in `colors-fonts/` once the logo is chosen.

## Logo concepts to brainstorm

2. **Brushstroke chevron**: a military rank chevron painted as a single brushstroke. Service, then art.
3. **Dog tag + paint**: a dog tag with paint splattered across it, or with a brush-lettered "BRAVE" stamped on it.
