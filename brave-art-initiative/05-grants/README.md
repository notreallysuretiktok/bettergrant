# Grants

Almost every grant application asks the same questions. Write the answers once here, then adapt them per funder.

## Boilerplate to write (in this order)

1. **Mission statement** (1 sentence)
2. **Vision** (1 sentence)
3. **Org history** (founding story, 150 words)
4. **Problem statement**: why veterans and survivors need creative outlets, with 2–3 cited statistics
5. **Programs**: copy from `../03-programs/`
6. **Outcomes and how you measure them**
7. **Founder / leadership bio**: copy from `../04-media-kit/`
8. **Annual budget**: one simple table
9. **Board list**: names and roles only (no personal contact info in this public repo)

## Legal docs funders will ask for (keep private, not in this repo)

- IRS 501(c)(3) determination letter
- EIN
- State registration
- Most recent Form 990 or 990-N
